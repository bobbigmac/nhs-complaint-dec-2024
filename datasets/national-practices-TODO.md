# National Practices TODO

This file tracks the cleanup work needed to get the national-practices supplemental layer and the Manchester core Google capture into a cleaner, more explicit state.

Important scope split:

- The Greater Manchester core dataset is allowed to collect extended or full Google review history where that is useful.
- National supplemental practice records are not meant to get full-history review crawls as a default. For supplementals, the main goal is to recover usable rating/count/recent-card coverage and to replace ambiguous blanks with explicit states.

on extended reviews, I think we'll be able to pull more reviews further down the page, but instead of a number of reviews limit, let's set a time-between pulls of new review sets (i.e. scroll down more, add a jiggle off the bottom before trying to scroll down again harder, to trigger the correct pull from google's client code) and log an exit state if it takes more than 5 minutes between extended reviews get added to the retrived pool, so when it really chugs to a crawl, we can just exit out there, and log like exited_early_at so we know there are reviews we couldn't get
