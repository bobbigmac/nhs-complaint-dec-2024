# Context Notes

This folder holds the source-of-truth markdown used for the site-level context pages.

Current inputs:

- `GTD_CHRONOLOGY.md` - dated working log for GTD, New Bank, procurement, governance and related signals
- `OPERATING_ENVIRONMENT.md` - organisational / commissioner / competitor environment around GTD
- `GTD_INQUIRY_LINKS.txt` - deduplicated link dump preserved from the inquiry JSON export

The site build reads these files directly when generating the rendered `chronology/` and `environment/` pages.
