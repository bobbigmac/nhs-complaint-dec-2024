# What this homepage is for

This site is the quickest public route into a repo that has grown across complaints, meeting packs, printoffs, survey work and mapping. Instead of mirroring the folder structure, the homepage groups the material into a small number of issues so a new reader can see the problem, the work already done, and the best evidence to open next.

## How to use it

- Start with the issue panels if you want the narrative.
- Use the map and download bundle if you want the latest Greater Manchester comparison data.
- Use any `Print view` link to open a markdown note in the bundled print utility without leaving the site.

## Working principle

The argument throughout is simple: primary care access has to tolerate real life. If the front door depends on perfect daytime availability, repeated form-filling, or unscheduled calls that close the case when missed, the service is selecting for the easiest patients rather than the patients who need it most.
